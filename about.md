# Multiplayer Editor
### Made by **x7wv**

Build Geometry Dash levels **live** with your friends. Every block, move, rotate and trigger edit shows up for everyone instantly.

## Features
- **Instant sync** of placing, deleting, moving, rotating, scaling, pasting and editing objects
- **Level settings sync** (gamemode, speed, background, ground, font, song, guidelines)
- **Live cursors** with names, and **selection outlines** in each player's color
- **Playtest ghosts**: watch your teammates' icons while they playtest
- **Ghost camera**: follow a teammate or jump to where they're looking
- **Chat** with typing indicator, **pings** ("look here!") and an **activity feed**
- **Roles**: Host / Builder / Decorator / Viewer
- **Host tools**: kick, ban, transfer host, join approval, freeze room, chat slow mode, edit rate limit, password, welcome message
- **Lock objects** so finished parts can't be touched
- **Room browser** with tags, and **invite codes** you can paste in Discord
- **Auto-reconnect + offline mode**: keep building if your connection drops, and your edits merge back in when you reconnect
- **Timeline / time travel**: restore the level to any earlier point
- **Per-player undo**, **build requests** (tasks), **votes**, a **shared stopwatch**
- **Template library**, **group ID manager**, **leaderboard**, **timelapse replay**
- **Heatmap** of who built what, **draw mode** for sketching ideas, **reactions**
- **Auto collab-credits** text added to your level in one tap
- **Color channel sync**
- **Achievements**, sound effects, confetti when the level is finished, and 5 UI themes

## How to use
1. Set the **Server URL** in the mod settings (whoever hosts the server gives you this).
2. Open a level in the editor and press **MP → Host This Level**.
3. Send your friends the room code. They press **MP** on the main menu → **Join by Code**.
